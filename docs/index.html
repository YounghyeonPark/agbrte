What that buys

Quitting does not stop a turn

Two machines on one session see one transcript. A prompt raised on either is answerable from the other.

Everything resumes from its log

Which agent ran, under which model, and who approved each thing it needed.

Sessions can work as a team

Group them and they reach each other — a message that wakes one, or a read of what it has been doing.

A workflow is a file

The decomposition is written down and reviewed in a diff, so an agent can propose one without running it.

That machine’s ports and screen

A plain tunnel brings a dev server here. A remote window shows a few frames a second, with nothing installed there.
